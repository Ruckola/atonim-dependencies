# Deepgram TTS profile

Create a Deepgram API key with Text-to-Speech access and billing/usage permission, then download `recipes/deepgram/deepgram-tts-v1.0.0.json` and use **Import Profile…** in Atonim. Enter the key in Configure, choose an Aura 2 voice model, and keep the MP3 output setting unless you intentionally publish a compatible new profile version.

This profile is structurally validated against Atonim's generic HTTP contract and Deepgram's documented REST API. It has not made a paid synthesis request or completed clean-build GUI/provider acceptance.
