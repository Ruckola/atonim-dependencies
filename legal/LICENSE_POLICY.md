# Public repository license policy

No umbrella open-source license has been granted to third-party binaries, models, dictionaries or future runtime packages by this repository. Each published component must carry its own provenance, applicable license texts and required notices.

This repository currently contains original documentation and manifest contract material but has **no repository-wide LICENSE file**. Public access to source files is not, by itself, an open-source redistribution grant.

Before public binary releases: complete per-component legal review, SBOM, notices, checksum verification and security/authenticity design as described in `docs/DISTRIBUTION_CONTRACT.md`.
